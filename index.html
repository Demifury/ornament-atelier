F / 0 / 1Fit design / fit centre (Straight: fit artboard) / 100%
DeleteRemove selected layers
Ctrl + GGroup the selected layers
Ctrl + Shift + GUngroup the selected layers
Scroll over a badgeChange its value by 1 (Shift: by 10)
Drag a badge left / rightScrub its value (Shift: coarser); a plain click types one

EnterConfirm layer rename
EscCancel layer rename
